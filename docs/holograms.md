# Голограмма над горящим зарядом

Над подожжённым динамитом появляется табличка с обратным отсчётом: сколько
секунд осталось до взрыва. У снаряда тротиловой пушки табличка едет вместе с
зарядом, поэтому видно, где он сейчас и когда рванёт.

Подсистема перенесена из QweProtectStones (голограммы над ядром привата) и
переделана под временный объект: не «пока стоит приват», а «пока горит
фитиль».

## Как включить

Голограммы включены по умолчанию. Секция `holograms:` лежит в корне
`config.yml` (не внутри `settings:`):

```yaml
holograms:
  enabled: true
  provider: AUTO
  max-active: 48
  follow-projectile: true
  update-interval-ticks: 5
  offset: 1.1
  display-range: 24
  lines:
    - "<#FDE68A>⚡ <#F2EFFA>%seconds% с"
    - "<#A79FC0>%name%"
  settings:
    see-through: false
    shadow: true
    scale: 1.0
    billboard: CENTER
    text-alignment: CENTER
    background: ""
    permission: ""
```

Выключить полностью — `enabled: false`. Опустошить `lines` — тоже
выключит: показывать нечего.

## Провайдеры

| `provider` | Что делает |
| :--- | :--- |
| `AUTO` | Пробует FancyHolograms, затем DecentHolograms, затем встроенные |
| `FANCY` | FancyHolograms; если плагина нет — встроенные |
| `DECENT` | DecentHolograms; если плагина нет — встроенные |
| `NATIVE` | Всегда встроенные голограммы на `TextDisplay` |

Правила:

- Регистр и пробелы в значении не важны (`fAnCy` = `FANCY`). Неизвестное
  слово — как `AUTO`.
- Мосты подключены как `provided`: они не попадают в JAR аддона, поэтому без
  установленного плагина голограммы просто рисуются встроенными — без ошибок
  в консоли.
- **На Folia всегда `NATIVE`.** FancyHolograms и DecentHolograms на Folia не
  работают, и аддон даже не пытается их подключить: мосты там не создаются
  вовсе.
- Ванильный TNT аддон не оформляет: голограммы только у своих динамитов.

## Все ключи

Верхний уровень секции `holograms:`:

| Ключ | По умолчанию | Что делает |
| :--- | :--- | :--- |
| `enabled` | `true` | Голограммы вообще |
| `provider` | `AUTO` | `AUTO`, `FANCY`, `DECENT`, `NATIVE` |
| `max-active` | `48` | Предел числа голограмм на сервер; `0` — без предела |
| `follow-projectile` | `true` | Ехать за зарядом; `false` — стоять там, где подожгли |
| `update-interval-ticks` | `5` | Как часто обновлять отсчёт (и позицию) |
| `offset` | `1.1` | Высота над зарядом в блоках (от −2 до 8) |
| `display-range` | `24` | С какого расстояния видно, в блоках |
| `lines` | 2 строки | Текст; поддерживает MiniMessage |

Внутри `holograms.settings:` — внешний вид, ключи те же, что в
QweProtectStones:

| Ключ | По умолчанию | Что делает | Где работает |
| :--- | :--- | :--- | :--- |
| `see-through` | `false` | Видно сквозь стены | все |
| `shadow` | `true` | Тень текста | все |
| `scale` | `1.0` | Масштаб (0.1…8) | все |
| `billboard` | `CENTER` | `CENTER`, `VERTICAL`, `HORIZONTAL`, `FIXED` | все |
| `text-alignment` | `CENTER` | `LEFT`, `CENTER`, `RIGHT` | все |
| `background` | пусто | Подложка, `#RRGGBB` или `#AARRGGBB` | все |
| `permission` | пусто | Право на просмотр | только DecentHolograms и FancyHolograms |

> [!NOTE]
> `permission` — единственный ключ, который встроенный провайдер не
> поддерживает: отфильтровать зрителей по праву умеет только сам плагин
> голограмм. При заданном праве аддон один раз напишет в лог
> «Право на просмотр для встроенных голограмм не поддерживается» и покажет
> табличку всем.

Значения вне диапазона обрезаются по границам: `max-active` — до 512,
`offset` — до −2…8, `scale` — до 0.1…8, `display-range` и
`update-interval-ticks` — не меньше 1. Опечатка в конфиге не превращается в
тормозящий сервер таймер.

## Подстановки в строках

| Подстановка | Что показывает |
| :--- | :--- |
| `%seconds%` | Секунд до взрыва (округлено вверх: пока осталось 2,1 с — видно «3») |
| `%ticks%` | Тиков фитиля |
| `%name%` | `display_name` динамита |
| `%player%` | Кто поджёг; неизвестен — прочерк «—» |

Строки — обычный MiniMessage, та же палитра, что в остальных сообщениях:
`#FDE68A` (значение), `#F2EFFA` (текст), `#A79FC0` (пояснение), `#FB7185`
(опасность).

## Своя голограмма у динамита

У любого динамита может быть секция `hologram:` — она **накладывается** на
общие настройки, а не заменяет их целиком:

```yaml
# dynamites/c4.yml
hologram:
  enabled: true
  lines:
    - "<#FB7185>☠️ <#F2EFFA>%seconds% с"
    - "<#A79FC0>%name% · %player%"
```

Чего в секции нет, берётся из `config.yml` — поэтому правка общих настроек
продолжает действовать на те динамиты, где ключ не задан явно. Отключить
голограмму у одного типа:

```yaml
hologram:
  enabled: false
```

## Жизненный цикл

| Событие | Что происходит |
| :--- | :--- |
| Заряд создан (`PrimingService`) | Голограмма показана; если предел `max-active` исчерпан — молча пропущена |
| Каждые `update-interval-ticks` | Пересчитан отсчёт, обновлена позиция (если `follow-projectile`) |
| Тик нашёл заряд мёртвым | Голограмма убрана (заряд мог исчезнуть и без взрыва) |
| Взрыв (даже отменённый) | Голограмма убрана сразу, не дожидаясь тика |
| `/qtnt reload` | Все голограммы убраны, провайдеры пересозданы |
| Выключение плагина | Все голограммы убраны |

Позицию и текст голограмма получает только на главном потоке — на Paper
через `RegionScheduler` по месту заряда, на Folia через планировщик самой
сущности. Из другого потока сущности не трогаются.

## Производительность

- **`max-active`.** Зажгли сотню зарядов — нарисовано будет не больше
  `max-active` табличек. Остальные молча пропускаются: лучше без таблички,
  чем с просадкой TPS.
- **Один глобальный таймер**, а не задача на каждый заряд. Когда голограмм
  нет, тик ничего не делает и выходит сразу.
- **Позиция обновляется только если заряд реально сдвинулся.** При
  `follow-projectile: false` точки совпадают, и лишний пакет клиентам не
  отправляется.
- **Таблица не попадает в мир.** Встроенные голограммы создаются с
  `setPersistent(false)`, голограммы мостов — с «не сохранять в файл».
  После рестарта в мире не остаётся `TextDisplay` без хозяина и в конфиге
  DecentHolograms не остаётся мусора.

## Отличия от QweProtectStones

| | QweProtectStones | QweTnts |
| :--- | :--- | :--- |
| Ключ карты | UUID привата | UUID заряда (`TNTPrimed`) |
| Время жизни | пока стоит приват | пока горит фитиль |
| Позиция | статична | обновляется вместе с отсчётом |
| Кэш чанков | слушатели загрузки/выгрузки | не нужен: уборка по взрыву и гибели заряда |
| Подстановки | `%owner%`, `%durability%`, `%siege%` | `%seconds%`, `%ticks%`, `%name%`, `%player%` |
| Предел числа | по привату — одна | `max-active` на весь сервер |

Из QPS не перенесены: привязка к региону и кэш чанков, отдельные строки «под
атакой», подстановки привата, ключи только для DecentHolograms
(`down_origin`, `update_range`). Добавлены: `max-active`,
`follow-projectile`, уборка по взрыву и гибели заряда, секция `hologram:` у
динамита.

## Если что-то не так

**Голограммы нет.** Проверьте по порядку:

1. `holograms.enabled: true` и в `lines` есть строки.
2. У динамита нет `hologram.enabled: false`.
3. Это свой динамит, а не ванильный TNT — ванильный аддон не оформляет.
4. Не исчерпан ли `max-active` (предел общий на весь сервер).
5. В логе нет предупреждения о `permission` — праве, которое встроенный
   провайдер не понимает (голограмма при этом всё равно показывается).

**Установлен FancyHolograms, но рисуются встроенные.** Плагин должен быть
включён к моменту старта аддона. Провайдеры создаются при старте и при
`/qtnt reload` — после появления плагина перезагрузите аддон.

**Цифры меняются рывками.** Это `update-interval-ticks`. По умолчанию 5
тиков — четыре обновления в секунду; уменьшите до 2, если нужна плавность,
и помните, что чаще — дороже.

**Табличка осталась после того, как динамит уже рванул.** Такого быть не
должно: уборка висит на `EntityExplodeEvent` и на тике. Если увидели —
пришлите в issue версию сервера и тот факт, что взрыв был отменён
(отменённые тоже убираются).
